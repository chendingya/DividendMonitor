# Android 多资产与录入验收（2026-10-30）

本次补充此前股票持仓、账号和云恢复验收未覆盖的 ETF、基金、贵金属、房产和日历链路。测试设备为 Android 15 x86_64 专用模拟器；不是 Vivo X80 / OriginOS 6 真机结论。

## 实际修复

- 红利 ETF `510880` 源站的“每10份派现金1.4300元”归一为 `0.1430 元/份`。没有分红时仍展示资产身份、行情、画像及走势图，只有分红区域显示空态。
- 修改资产代码后清除旧身份，识别请求不能覆盖后续输入；同码歧义或部分源失败时，数字代码需明确类型后识别。搜索页提示结果不完整，本地金银结果不因其他源故障丢失。
- 买入费用加佣金，卖出回款减佣金。未改成交价的旧交易保留原成本，不按新设置重复收费；编辑已除权交易日期时用缓存逆序还原后重放。缺少必要历史记录、成本曾截断为零时拒绝猜测；缺原成交价的旧交易需分别修改数量与日期。
- JSON 持仓转移保留成交价、日期、风险和除权游标，避免导入已调整的股数及成本后再次除权。
- 房产现有业务是每个城市一组区/小区参数。整套总价和整套月租金成对计算，不与每平方米行情混算；详情、首页和跨资产来源一致。写入失败与写入成功后的刷新失败分别提示；保存后复用已有市场快照回读本地数据。
- 持仓及回测使用中文 Ant Design DatePicker，分红统计保留 Ant Design RangePicker，手机范围面板纵排。详情和回测指标改为窄屏布局，房产输入与主要操作的触控高度至少 44px。
- 贵金属空报价不当作成功缓存，新浪失效时可使用已有东方财富后备源；国际代码保留新浪要求的 `hf_` 前缀。白银报价及历史价格从元/千克归一为共享详情使用的元/克。

## 界面测试入口

`NativeExtendedFlowTest` 默认跳过，必须显式传 `extendedPhase`；只在已退出登录的专用测试安装执行。`entries` 使用默认佣金设置，要求保留测试账号恢复的工商银行两笔共 200 股，并且 `510880`、`160222`、`AU9999` 没有既有持仓；`housing` 要求北京没有既有自定义金额。不要在个人数据安装上运行。

```powershell
adb shell am instrument -w `
  -e class com.chendingya.dividendmonitor.NativeExtendedFlowTest `
  -e extendedPhase etf `
  com.chendingya.dividendmonitor.test/androidx.test.runner.AndroidJUnitRunner
```

| extendedPhase | 实际操作和断言 |
| --- | --- |
| `etf` | 搜索“红利ETF”，原生触摸名称进入 `510880` 详情；核验身份、价格走势图、手机两列指标及无页面横向溢出 |
| `details` | 分别搜索并打开 `160222`、`AU9999`、`AG9999`；基金价格图，金银正报价、克/盎司切换及 31.1035 换算关系 |
| `dates` | 实际点击持仓日期、回测日期和分红日期范围的 Ant Design 面板；选中日回写、中文和手机弹层宽度 |
| `entries` | 茅台识别后改为红利 ETF；录入 300 份、编辑为 250 份，再买 100 份、卖 100 份；核验 250 份/3 笔及净成本 755 元；Activity 重建后再次验证；删除整项，并录入、删除基金及黄金；原 200 股不受影响 |
| `housing` | 北京总价 500 万/月租 8000，收益率 1.92%；返回重进、改月租 10000 得 2.40%；Activity 重建读回；清除；总价 300 万、首付 30%、30 年、3.1% 房贷计算；表单触控和页面宽度 |
| `backtest` | ETF 详情进入回测，等待真实回测摘要、分红结果和 Canvas 图表，检查页面宽度 |
| `cleanup` | 清除本专用安装中失败测试遗留的 `510880` 持仓，仅用于维护测试夹具 |

字段通过 WebView 原生输入值与 DOM 输入事件填写；按钮、菜单、日历通过 Android MotionEvent 触摸。测试不导入业务 API、不预置数据库；仓储和原生插件的单独测试不冒充界面端到端测试。

## 验证结果

- TypeScript 检查、101 个 Vitest 文件 / 629 项测试、Electron 生产构建、移动资源和 Android APK 构建通过。
- 411px 下上述六个界面阶段通过；最后的日历定位修改后重新验证受影响的资产录入与日历阶段。原生运行时及基础界面 7 项回归同时运行通过（54.962 秒），包含未提交事务回滚及后续 Activity 正常启动。
- 360px 下日历 35.952 秒、ETF 详情 31.009 秒、房产 50.980 秒、回测 29.692 秒通过。日历验收曾确实失败：触控网格放大后弹层 `left=-17px`；现按可视区域定位，360px 上实际范围为 `8..352px`。已恢复原始模拟器显示密度。
- 最终包使用既有专用账号真实登录（8.770 秒）、云端拉取 1 条自选和 2 笔共 200 股（11.935 秒，持仓在拉取后 2992ms 展示）、退出登录并从本地重新验证自选和 200 股（22.583 秒）。没有为这些步骤清空 App 数据；不将本轮结果称为空安装云恢复测试。
- 最终包强制停止后重新启动，自选和 200 股持仓验证通过（38.944 秒）。
- 安装包包含 `arm64-v8a`，APK v2 签名通过。交付包 `release/android/shou-xi-lao-0.3.0-mobile-extended-debug.apk`（26,470,987 字节），SHA256 为 `edb79e8f6dc6e59d15fe7942c5184da87ef5ea708a58b30e50768e37c9102b03`。这是调试签名包，不是商店签名发布。

## 覆盖边界

- 本轮金额、日期/除权、JSON、失败反馈和部分数据源失败有受控回归；真实外网只证明执行时的公开源可用，不保证之后始终可用。
- 仓储只有最后除权日期，没有逐项已应用日志，因此不能检测历史区间中某个中间事件被单独删掉的所有情况。
- 真机系统回收、多台设备并发编辑、其他未列出的业务模块、原生文件分享和商店发布不在这些测试的通过结论内。已有平台限制仍见 [Android 构建文档](ANDROID-BUILD.md)。
